# Tooling disclosure

ShromikAI was built with the help of AI tools. The team reviews, runs and is responsible for all AI-generated code and output.

| Tool | Used for |
| --- | --- |
| Claude (Anthropic) | Project planning, architecture design, writing backend and frontend code, documentation |
| Claude API | Runtime: clause classification, risk analysis, citation support check, Bangla memo |
| bge-m3 (via Ollama) | Runtime: multilingual embeddings for law search |
| ChatGPT (OpenAI) | Second-opinion review of the project plan |

The key development prompts and their results are recorded in [dev-log.md](dev-log.md).
