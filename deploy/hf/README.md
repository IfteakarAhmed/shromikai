# ShromikAI (শ্রমিকAI) — recorded demo

Verified employment-contract intelligence for Bangladesh. **This Space is a recorded demo:** it
replays the recorded model answers of one synthetic sample contract (worker's side, Bangla). No live
model, no cloud call and no API key is involved, and nothing you do here is sent anywhere. Results
are labelled "recorded". ShromikAI is not legal advice (এটা আইনি পরামর্শ নয়).

- One-click demo login: `/demo-user` (worker), `/demo-hr`, `/demo-admin`.
- Docs and evaluation numbers: `/docs`. API reference: `/swagger-ui`.
- Open the direct `*.hf.space` address in its own tab; the sign-in cookie does not work inside the
  embedded view on huggingface.co.

Source, specification and evaluation: see the project repository. Deployment design: ADR-0026.
